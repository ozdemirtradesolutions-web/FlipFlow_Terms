## 2. Description of Service

FlipFlow is a digital wellbeing application that helps users reduce doomscrolling by encouraging hydration resets. The App:

- Monitors usage of social media apps you select (using Apple's Screen Time API and FamilyControls framework).
- Temporarily blocks selected apps when usage thresholds are reached.
- Requires a short camera recording of you drinking water as verification to unlock blocked apps.
- Provides a discrete reset option for quick hydration verification.
- Tracks your hydration resets, streaks, and provides usage statistics and personalized insights.
- Sends local reward notifications for focus achievements and habit improvements.

All data processing occurs locally on your device. FlipFlow does not operate backend servers for user data processing.
